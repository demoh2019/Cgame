# Arcade Starter 2D

A tiny, runnable Godot 4.x demo with no external assets.

## Play
Open res://ai_generated/main.tscn and press F6 (Run Current Scene).
Move with WASD or arrow keys. Collect ten green blocks within 60 seconds.
Press R to restart after winning or timing out.

This starter is deterministic local content. It does not call AI or use an API key.

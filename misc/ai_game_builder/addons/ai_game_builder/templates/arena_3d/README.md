# Offline 3D Arena Starter

Playable, self-contained Godot 4.x 3D game: procedural mesh arena, player movement,
fixed collectible targets, perspective camera, directional light, score and timer.

## Run

In the AI Game Builder dock click **Preview offline 3D starter (no API key)**.
Review the 3 generated files and click **Apply reviewed files**. Open
`res://ai_generated/scenes/main.tscn` and use **Run Current Scene (F6)**.

Move with WASD or arrow keys, collect 6 green boxes within 90 seconds,
then press R to restart. The camera looks down at the arena from above.

No API key, network, imported assets, external plugin or custom input action is
required. The preview/apply flow does not run generated game code automatically.
This is a starter prototype, not a physics-driven first-person controller.

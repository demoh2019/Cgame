# scavenging.gd

> Server-only scavenging risk/reward rules for real, one-use ruin crates.

`res://scripts/shared/scavenging.gd`

## Overview

Server-only scavenging risk/reward rules for real, one-use ruin crates.
No client-controlled loot, XP, bonus count or zone values.

- `const Defs = preload("res://scripts/shared/defs.gd")`

## Functions

### `can_unlock`

```gdscript
static func can_unlock(zone: int, owned_kits: int) -> bool
```

Only the authoritative crate's zone and server inventory permit unlocking.

### `sealed_compartment_loot`

```gdscript
static func sealed_compartment_loot(zone: int, rng: RandomNumberGenerator) -> Dictionary
```

Contents are bounded and come exclusively from the server RNG. Valuable
weapons and rare raid trophies cannot be generated by lockpicks.

### `enriched_loot`

```gdscript
static func enriched_loot(zone: int, level: int, base: Dictionary) -> Dictionary
```

Extra mundane salvage; valuable weapons/medicine remain ordinary RNG loot.
Only red/black crates at level >= 2 get an additional, bounded scrap yield.

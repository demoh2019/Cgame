# Адаптивный CPU-бюджет стриминга мира

Нативное расширение `WorldStreamer` для Albion After. При серии длинных
кадров движок временно уменьшает число новых чанков и время, выделенное
на их создание в основном потоке. Очередь не очищается, фоновая загрузка
ресурсов не отключается, радиусы загрузки и выгрузки не меняются.

## Прямое применение в Albion After

```gdscript
streamer.max_instantiations_per_frame = 3
streamer.max_chunk_work_usec = 2500
if "adaptive_chunk_budget_enabled" in streamer:
    streamer.adaptive_chunk_budget_enabled = true
```

Настройка выключена по умолчанию в движке, чтобы сохранить совместимость
с другими проектами и старыми сборками Cgame. В Albion After она включается
только при наличии соответствующего API.

Длительность кадра свыше 30 мс повышает давление на 0,16; кадр короче
20 мс снижает его на 0,05. Между 20 и 30 мс давление сохраняется.

| Давление | Новых чанков на кадр | Мягкий лимит CPU |
| --- | ---: | ---: |
| Менее 40% | 3 | 2500 мкс |
| 40–79% | 2 | 1875 мкс |
| 80–100% | 1 | 1250 мкс |

Это **мягкий**, а не жёсткий лимит: уже начатое создание чанка нельзя
прервать. При высоком давлении сохраняется хотя бы один слот на кадр,
поэтому механизм не приводит к полной остановке стриминга.

## Профилирование движка

Новые нативные методы:
- `get_last_frame_chunk_work_usec()` — фактическое CPU-время генерации,
  подключения сцены и её колбэков, но без декодирования ресурсов в потоках.
- `get_last_frame_chunk_attempt_count()` — число попыток, включая пустые
  и ошибочные чанки.
- `get_streaming_frame_pressure_percent()` — давление 0–100%.
- `get_effective_instantiations_per_frame()` — реальный лимит количества.
- `get_effective_chunk_work_usec()` — активный мягкий бюджет времени.

Пять показателей регистрируются в Debugger → Monitors с префиксом
`Albion/Stream`. При закрытии игровой сцены показатели удаляются.

Улучшение производительности и совместимость с реальным GPU можно
подтвердить только после компиляции Cgame и измерения времени кадров.
Нативный код и проверка исходников сами по себе этого не доказывают.

# Cgame — нативная гидростатика мягких тел

Отдельная сцена демонстрирует **встроенную физику C++ GodotPhysics3D**:
на замкнутую поверхность `SoftBody3D` действует давление воды,
зависящее от глубины погружения. В отличие от `buoyant_box.gd`
в Physics Lab, силы **не рассчитываются в GDScript**.

## Модель

Плоскость воды — `y = 2`, плотность — `2.5 кг/м³`.
Два одинаковых замкнутых деформируемых куба объёмом `2.4³ = 13.824 м³`
имеют разную массу: зелёный **6 кг**, оранжевый **45 кг**.
Дополнительно есть **жёлтая открытая ткань** (25 вершин):
на неё **не действует гидростатика**, но действует течение воды.
В демонстрации включён горизонтальный поток `Vector3(1.5, 0, 0)`.
Полная потенциальная вытесняющая масса воды ≈ `34.56 кг`:
при корректной работе гидростатики зелёный должен стремиться к
всплытию, а оранжевый — к погружению.

Гидростатическое давление интегрируется **точно для линейного
распределения глубины на каждой отсечённой части треугольника**.
Плоскость воды обрезает поверхность; результирующая сила распределяется
по исходным вершинам через барицентрические коэффициенты P1.
При полной иммерсии замкнутого меша результирующая равна `ρ g V`
по закону Архимеда. Интегрирование идёт на динамически
деформируемой поверхности, без специальных визуальных эффектов.

## Запуск на Mac

Из корня Cgame, после сборки актуального GodotPhysics3D:

```sh
git checkout develop && git pull origin develop
./bin/godot.macos.editor.$(uname -m) --path demo/softbody_hydrostatic_lab
```

Smoke-тест:

```sh
./bin/godot.macos.editor.$(uname -m) --headless --path demo/softbody_hydrostatic_lab --script res://smoke_test.gd
```

Клавиша **R** перезапускает сцену, **Esc** закрывает её.

## Как активировать в собственном проекте

В уже существующий раздел `[physics]` файла `project.godot` добавь:

```ini
3d/physics_engine="GodotPhysics3D"
3d/fluid_plane/enabled=true
3d/fluid_plane/surface_height=2.0
3d/fluid_plane/density=1000.0
3d/solver/soft_body_hydrostatic_pressure=true
# Отдельные настраиваемые гидродинамические силы для SoftBody3D.
3d/solver/soft_body_hydrodynamic_drag=true
3d/solver/soft_body_hydrodynamic_tangent_ratio=0.35
3d/fluid_plane/drag_coefficient=0.8
3d/fluid_plane/flow_velocity=Vector3(1.5, 0, 0)
```

`density=1000` — вода при единицах мира, интерпретируемых как метры
и масса в килограммах. Демонстрация использует меньшую плотность для
лучшей наглядности объектов небольших масс.
В модели используется **вертикальная гравитация мира по направлению -Y**.
При существенном горизонтальном компоненте гравитации гидростатическая
сила не применяется — горизонтальная поверхность тогда физически
несогласована с направлением тяжести.

Новая опция по умолчанию **отключена**, как и сама плоскость жидкости.
Вычисление требует замкнутую, корректно ориентированную оболочку.
Неизолированная ткань/открытая сетка не получает фиктивную плавучесть.
На каждую грань добавляется фиксированная работа без выделения памяти
в кадре. Уровень, плотность и выбранный бэкенд загружаются при
создании физического пространства.

## Новая гидродинамика: поток и вязкое сопротивление поверхности

Сопротивление рассчитывается **не по объёму**, а по погружённым
участкам каждого треугольника сетки. Оно действует на замкнутые
мягкие тела и **открытую ткань**. Относительная скорость
`u = v_поверхности − v_жидкости` разделяется на две компоненты:
нормальную и касательную. Для каждой применяется квадратичное
сопротивление, пропорциональное `0.5 * плотность * Cd * площадь`.

Частично погружённые треугольники разбиваются на части по уровню
воды с сохранением барицентрических координат. Их импульсы
распределяются между **тремя исходными физическими вершинами**.
Расчёт работает с открытыми поверхностями, поэтому не зависит
от проверки объёма, которую требует гидростатика.

Перед применением импульс ограничивается так, чтобы
**не увеличить кинетическую энергию относительно текущей скорости
жидкости**. Скорости обновляются сразу после каждого треугольника,
а не все одновременно по устаревшим скоростям. Это защищает от
чрезмерного сопротивления при больших коэффициентах, скорости и
временном шаге. Нулевые настройки не добавляют проход по сетке.

Включение `soft_body_hydrodynamic_drag=true` допускается отдельно
от `soft_body_hydrostatic_pressure`. Общие с жёсткими телами настройки:
`fluid_plane/drag_coefficient`, `fluid_plane/density`,
`fluid_plane/flow_velocity`.
Опция `soft_body_hydrodynamic_tangent_ratio` задаёт относительное
касательное трение; `0` оставляет только нормальное.

## Границы реализации

Это **гидростатика + приближённая гидродинамическая сила
сопротивления**, а не полноценный FLIP/SPH/CFD-солвер.
Нет брызг, волн, пространственного распределения течения или
обратного воздействия мягких объектов на жидкость. Поток
пока однороден и задаётся параметром проекта. Плотность и Cd
являются феноменологическими коэффициентами — их нужно подбирать
под масштаб сцены, массу и шаг физики. Включённая настройка
добавляет O(количество треугольников) расчётов на каждый физический
кадр, **без новых динамических массивов**.

Закон Архимеда справедлив для замкнутой ненарушенной поверхности.
Тесты: `tests/servers/test_physics_softbody_hydrostatic.cpp`,
`tests/servers/test_physics_softbody_hydrodynamic_drag.cpp`,
`tests/stress/test_physics_softbody_hydrostatic.py` и
`tests/stress/test_physics_softbody_hydrodynamic_drag.py`.
